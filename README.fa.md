# WEJET — مستندات جامع فارسی

> **میزکار شما. فضای شخصی شما.**  
> **Your desktop. Your space.**

**WEJET (ویجت)** یک محیط دسکتاپ شخصی، بومی، فوق‌سبک و شیشه‌ای برای **ویندوز ۱۱ و ویندوز ۱۰** است که با **Rust**، **Tauri 2**، **React 19**، **TypeScript** و موتور سیستمی **WebView2** ساخته شده است.

برخلاف ابزارهای سنگین مبتنی بر Electron یا ویجت‌سازهایی که به ازای هر ویجت یک پنجره و WebView جداگانه باز می‌کنند، Wejet **تمامی ویجت‌های دسکتاپ را درون یک لایه شفاف واحد (`Desktop Layer`)** اجرا می‌کند که از طریق Win32 `WorkerW` دقیقاً روی تصویر پس‌زمینه واقعی ویندوز و پشت پنجره‌های عادی قرار می‌گیرد.

## امکانات کلیدی

1. **معماری دو پنجره‌ای واقعی (`Desktop Layer` + `Manager Control Center`)**
   - **لایه دسکتاپ (`?window=desktop`)**: تمام‌صفحه، بدون کادر، کاملاً شفاف، چسبیده به لایه پس‌زمینه ویندوز (`WorkerW` با بازگشت ایمن خودکار به `HWND_BOTTOM`)، قفل‌شونده با Click-Through واقعی Win32 (`WS_EX_TRANSPARENT | WS_EX_LAYERED`) و منوی کلیک‌راست شیشه‌ای بومی.
   - **مرکز مدیریت (`?window=manager`)**: پنل مدرن به سبک Windows 11 شامل **پیش‌نمایش زنده تعاملی دسکتاپ**، **گالری ویجت‌ها**، **فضاها (Spaces)**، **استودیو ظاهر و شیشه**، **ابزارک‌ها و تاریخچه کلیپ‌بورد**، **مودهای ایمن ویندوز** و **پشتیبان‌گیری / خروجی `.wejet`**.
2. **سیستم شیشه‌ای ۴ لایه (Graceful Glass Fallback)**
   - بهره‌گیری از DWM بومی ویندوز (`DWMWA_SYSTEMBACKDROP_TYPE` / Acrylic) ← `backdrop-filter` در WebView2 ← سطح نیمه‌شفاف تطبیقی ← سطح یکپارچه با کنتراست بالا برای سیستم‌های قدیمی، به همراه تنظیم مستقل شفافیت بدنه هر ویجت (**۲۰٪ تا ۱۰۰٪**) بدون افت خوانایی متن.
3. **پشتیبانی تراز اول از فارسی (RTL) و انگلیسی (LTR)**
   - چیدمان راست‌به‌چپ اصولی، اعداد فارسی اختیاری با عرض ثابت (`tabular-nums`)، تقویم کامل هجری شمسی + میلادی، مناسبت‌ها و تعطیلات رسمی داخلی، و تغییر آنی زبان بدون ری‌استارت.
4. **۸ ویجت بومی ثبت‌شده در `WidgetRegistry`**
   - **ساعت و تاریخ دوگانه** (۳ سبک: شیشه‌ای مینیمال، عقربه‌ای کلاسیک SVG، و تایپوگرافی درشت تحریریه)
   - **تقویم جلالی ماهانه** (همراه با بازه میلادی، مناسبت‌ها، تعطیلات و ثبت رویداد روزانه)
   - **آب‌وهوا و پیش‌بینی ۴ روزه** (متصل به سرویس Rust `OpenMeteoProvider` با کش دیسکی ۳۰ دقیقه‌ای و نمایش زمان آخرین بروزرسانی در حالت آفلاین)
   - **پایش زنده سیستم** (CPU، RAM، دیسک، شبکه RX/TX، دمای پردازنده + نمودار ۶۰ ثانیه‌ای SVG خالص بدون کتابخانه خارجی)
   - **تابلو نرخ ارز، طلا و رمزارز** (**دلار آمریکا**، **یورو**، **طلای ۱۸ عیار**، **سکه امامی**، **بیت‌کوین** و **اتریوم** با کش مقاوم آفلاین)
   - **یادداشت و فهرست کارها (Todo)** + میانبر سراسری **`Ctrl + Alt + N`** برای یادداشت فوری
   - **اجراگر سریع برنامه‌ها، پوشه‌ها و لینک‌ها** (با اعتبارسنجی امنیتی مسیر و `ShellExecuteW`)
   - **کنترل‌گر رسانه و موسیقی ویندوز** (متصل به WinRT `GlobalSystemMediaTransportControlsSessionManager`)
5. **ابزارهای بهره‌وری داخلی**
   - **مرکز فرمان شیشه‌ای (`Ctrl + Space`)**: جستجو، اجرای برنامه، ماشین‌حساب درجا (`(1280 * 1.15) + 250`)، تایمر سریع (`25 min`)، ثبت یادداشت سریع (`note ...`) و تغییر فضا یا پوسته.
   - **۵ ابزارک داخلی**: ماشین‌حساب، تایمر پومودورو، کرنومتر با ثبت دور (Lap)، مبدل واحدها و انتخابگر رنگ Accent.
   - **مخفی‌سازی هوشمند تمام‌صفحه (`Smart Hide`)**: تشخیص خودکار بازی‌ها و برنامه‌های تمام‌صفحه با مصرف نزدیک به صفر.
   - **مود ایمن ویندوز (`Safe Windows Mods`)**: نمایش/مخفی‌سازی آیکون‌های دسکتاپ با تهیه نسخه پشتیبان خودکار رجیستری در `mods-backup.json` و دکمه **بازگردانی کامل (`Revert All`)**.

## راهنمای سریع ساخت روی ویندوز و انتشار در GitHub

### ۱. اجرای محلی روی ویندوز ۱۰ یا ۱۱
پیش‌نیازها: **Node.js 20+**، **Rust Stable** و **Visual Studio C++ Build Tools**.

```bash
npm install
npm run tauri:dev
```

### ۲. ساخت نصاب نهایی MSI و NSIS EXE
```bash
npm run tauri:build
```
خروجی‌ها در مسیر `src-tauri/target/release/bundle/` تولید می‌شوند (`.msi` و `-setup.exe`).

### ۳. اتصال به GitHub و ساخت خودکار با GitHub Actions
مخزن از قبل دارای `.github/workflows/build-windows.yml` و `.github/workflows/release.yml` است:
```bash
git remote add origin https://github.com/<USERNAME>/wejet.git
git push -u origin main

# انتشار نسخه رسمی در بخش Releases گیت‌هاب به همراه MSI + EXE + SHA256SUMS.txt:
git tag v1.0.0
git push origin v1.0.0
```
